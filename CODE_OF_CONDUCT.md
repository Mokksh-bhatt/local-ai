# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in spirit: a short version is below.

## Pledge

We want a harassment-free space for anyone who files an issue, opens a PR, or uses the tool — regardless of age, disability, ethnicity, gender, experience, nationality, religion, sexual identity, or similar.

## Standards

Do:

- Be respectful and assume good intent
- Focus on the work (code, docs, bug reports)
- Accept that the maintainer may say no to keep the project small

Do not:

- Insult, harass, or threaten
- Post sexual or violent content
- Doxx or publish private information
- Troll, flame, or derail discussions

## Scope

This applies to GitHub (issues, PRs, discussions) and any other space where you represent the project.

## Enforcement

The maintainer may warn, hide comments, close issues/PRs, or block people.

Report problems with an issue titled `[conduct]` (keep details out of the public title if needed) or a GitHub private vulnerability/security report if the platform offers it. Do not expect a large enforcement team — this is a solo-maintained repo — but reports will be taken seriously.
